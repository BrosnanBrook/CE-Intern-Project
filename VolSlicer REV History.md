
# **VolSlicer Rev History**

## **1.0 - Introduces VolSlicer 1.0 software which includes the following.**

### **General Features**

* Added the ability to import .raw and .vti volumes
* Added slicing to create orthographic slices of the imported volume
* Added the ability to generate an example volume

### **Camera Features**

* Added ability to reposition orthographic slice images
* Added ability to zoom in/out
